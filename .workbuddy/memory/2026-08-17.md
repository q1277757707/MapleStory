## 冒险岛怀旧服辅助工具框架

用户想做一个冒险岛怀旧服辅助，功能包括加蓝、加红、寻路、找怪、释放技能。
采用 Python + 纯图色识别方案（不读内存，兼容性好，风险低）。

创建了完整项目框架：
- `config.py` - 全局配置（按键映射、血蓝条坐标、怪物模板、技能循环等）
- `capture.py` - 画面截图（mss 库）
- `detector.py` - 血蓝条检测（颜色采样）+ 怪物定位（OpenCV 模板匹配 + NMS 去重）
- `controller.py` - 按键输入（pydirectinput，DirectInput 兼容游戏）
- `pathfinder.py` - 寻路（简单方向逼近策略）
- `skill_manager.py` - 技能循环管理（优先级 + 冷却）
- `bot.py` - 主循环 + 状态机
- `main.py` - 启动入口
- `calibrate.py` - 血蓝条坐标校准工具
- `templates/` - 怪物模板图片目录
